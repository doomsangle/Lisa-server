## 三、KYC 分级与反洗钱条款（对应 6 风险 Ⅲ 类）

### 3.1 分级 KYC 强制规则（配置项 [system_configs.kyc_required_above](file:///d:/Lisa主机网络建设/metoe_backend/core/init_db.py#L455)）
| 用户行为触发阈值 | 必需 KYC 等级 | 对应数据表 |

| 单笔消费 / 月累计 ≥ ¥2000 且 < ¥20000 | **个人 KYC（Level 1）**：真实姓名 + 身份证号 + 正反面照片 + 人脸比对 | [kyc_verifications](file:///d:/Lisa主机网络建设/metoe_backend/core/init_db.py#L120-L148) 表 `type='person'` |

| **任何提现操作** | 至少 Level 1 KYC approved（`system_configs.kyc_required_for_withdraw=1`） | `users.status='active'` + `kyc_verifications.status='approved'` |

### 3.2 反洗钱（AML）条款
1. **资金来源声明**：用户通过 USDT/PayPal/银行转账充值时，声明资金来源为合法商业收入或劳动报酬，并非来自毒品、走私、赌博、诈骗、非法集资、恐怖融资等上游犯罪。
2. **USDT 链上溯源**：平台记录所有 USDT（TRC20/ERC20）充值的 `txid`（链上哈希）+ `confirm_count`（区块确认数）+ `from_address`（付款地址），存入 [payments](file:///d:/Lisa主机网络建设/metoe_backend/core/init_db.py#L195-L222) 表。单笔充值 ≥ ¥50000 将触发人工复核，并对接 Chainalysis / TRONSCAN 黑名单数据库，命中即冻结钱包 + 上报。
3. **提现 T+7 冷静期**：充值到账后 7×24 小时内禁止提现（`transactions.created_at` 计算），防止「跑分」「洗钱通道」「币混」等违规行为。
4. **大额交易报告义务**：根据香港《打击洗钱及恐怖分子资金筹集条例》（第 615 章）及适用法域要求，平台有权对 ≥ US$120,000 的年累计交易向相关监管机构提交 STR（可疑交易报告），**用户同意平台依法履行此报告义务且无需事先通知**。

### 3.3 KYC 数据用途范围
KYC 信息仅用于：① 身份核验；② AML 反洗钱筛查；③ 争议纠纷处理；④ 执法机构合法调取。**不得用于任何营销、第三方共享、数据售卖**（详见《隐私政策》第四节）。

### 6.2 DMCA 侵权通知与「通知-删除」程序（24h 处置 SLA）
美国版权法《数字千年版权法》（DMCA）合规：
1. **DMCA 代理人登记**：平台已向美国版权局登记指定代理人（信息可通过 [dmca.copyright.gov](https://dmca.copyright.gov) 查询；后台字段 `system_configs.dmca_agent`）。
2. **投诉渠道**：合格版权所有人或其授权代理人须向 `dmca@metoe.io` 发送符合 DMCA 要求的书面通知，包含：
   - (i) 权利人签章（电子签名有效）；
   - (ii) 被侵权作品的具体描述、URL 或 IP + 路径；
   - (iii) 涉嫌侵权内容的准确定位（VPS ID / 代理出口 ID）；
   - (iv) 权利人的联系方式（姓名、地址、电话、邮箱）；
   - (v) 善意声明（投诉有合法依据、非滥诉）；
   - (vi) 伪证处罚声明（签字人经授权且信息真实）。
3. **平台处置流程（24h SLA）**：
   ```
   收到合格 DMCA 通知 → 1h 内生成 feedbacks（priority=urgent）
        → 6h 内核实 URL / 服务器归属 → 12h 内暂停涉事 VPS 服务（vps_servers.status='stopped'）
        → 24h 内邮件通知上传者 + 提供反向通知（Counter-Notice）模板
        → 10-14 个工作日内未收到合格反向通知 → 内容永久删除并记录重复侵权次数
        → 收到合格反向通知 → 14 天观察期后恢复（双方自行走法院程序）
   ```
4. **重复侵权者封号**：同一用户 3 次 DMCA 合规下架（`user_dmca_takedowns.count >= 3`）→ **永久封号**（`users.status='banned'`）。
